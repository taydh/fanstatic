## POINTS OF INTEREST ![easy icon](https://park.annexdesk.com/resources/svgrepo/origami-filled-line-vector/hat-origami.svg) **Easy** We use basic techniques of HTML, CSS, and Javascript with few specific implementation to run script in template ![optimum icon](https://park.annexdesk.com/resources/svgrepo/origami-filled-line-vector/sword-origami.svg) **Optimum** We do not focus to be the fastest client-side rendering engine, but to be optimum with resource and cache ![personal icon](https://park.annexdesk.com/resources/svgrepo/origami-filled-line-vector/heart-origami.svg) **Personal** Codes executed by browser are everything that you wrote, no build tool required ![scalable icon](https://park.annexdesk.com/resources/svgrepo/origami-filled-line-vector/windmill-origami.svg) **Scalable** We try to make this engine scalable for typical frontend use cases like cms website, components, and apps
